# 回复去AI化质量层

一个让机器人回复更像真人的 AstrBot 插件。每次调用大模型前，它会给你的机器人注入一套"去 AI 腔"约束，拦下客服式收尾、空泛鼓励、无效总结这类模板表达，同时记住你最近回复里反复出现的开头，提醒模型换着说。

它做两件事：

1. **固定规则**：一套写给模型的通用约束，随每个请求注入。只做减法，不碰人设的性格、称呼、情绪和口头禅。
2. **动态提醒**：记录本会话最近回复的开头，某句开头重复够多、或命中自定义避用词时，下一轮提示模型换种说法。

## 它会拦下这类表达

- 客服式收尾：`希望对你有帮助`、`祝您愉快`
- 空泛鼓励：`这是一个很好的问题`
- 无效总结：`总的来说`、`综上所述`
- 破折号连发、`然而` 连发
- 最近几次回复都用同一句话开头（默认最近 8 条内出现 ≥3 次）
- 你自己配置的避用词（任意位置命中一次即生效）

## 工作原理

- **固定规则**随每个请求附加到 system prompt；**动态提醒**以本轮临时消息块注入，下一轮自动更新或移除。
- 注入的提示块带标记，不会重复累积，也不会写进聊天历史。
- 每次回复后更新会话状态，状态写盘在工作线程执行，不阻塞消息响应。

## 快速开始

1. 在 AstrBot 管理面板 → 插件市场导入本仓库，或手动将 zip 解压到插件目录；
2. 支持 AstrBot `>=4.23,<5`，版本不满足时会有兼容提示；
3. 默认全部开启，装完即可生效，无需配置。

> 修改配置后需在管理面板**重载插件**生效。

## 命令

指令组 `humanq`，全部子命令仅**管理员**可用，作用范围均为**当前会话**（不同群/私聊互不影响）。

| 命令 | 作用 |
|------|------|
| `/humanq status` | 查看当前会话状态与累计注入次数 |
| `/humanq on` | 启用当前会话 |
| `/humanq off` | 关闭当前会话（直到再次 on） |
| `/humanq reset` | 清空当前会话的提醒记录 |
| `/humanq rules` | 查看固定规则原文 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enabled` | true | 总开关。关闭后插件仍加载，但不注入规则、不记录状态 |
| `inject_stable_rules` | true | 注入固定规则。与其它改写 system 的插件冲突时可关闭 |
| `inject_runtime_state` | true | 注入动态提醒 |
| `max_runtime_hint_chars` | 600 | 每轮动态提示的最大字符数（80–3000，超界自动夹取） |
| `recent_reply_window` | 8 | 重复开头检测范围：统计最近 N 条回复的开头，同一开头出现 ≥3 次即提醒换说法（1–50） |
| `state_retention_days` | 14 | 会话状态超过该天数未更新自动清理（1–365） |
| `custom_cliches` | 空 | 自定义避用词，每行一个，命中即加入本轮提醒。建议单条 ≤20 字，超长不生效 |
| `disabled_sessions` | 空 | 禁用会话列表，每行一个群号（如 `123456`）或完整来源标识 |
| `debug_log` | false | 调试日志，开启后每次注入输出 debug 日志 |

旧配置项 `prompt_injection_mode` 已移除，留在配置文件里会被安全忽略。

## 数据与隐私

状态保存在插件数据目录的 `runtime_state.json`，只记录最近回复的开头与命中的避用词，**不保存完整聊天记录**。

## 测试（维护者）

```
python -m unittest discover -s tests -v
python -m compileall -q main.py quality_rules.py runtime_state.py tests
ruff format --check .
ruff check .
```

共 109 例。装有兼容 AstrBot 时以真实宿主运行；无宿主或版本不兼容时，真实宿主契约用例自动跳过，其余以假宿主模块运行。注意测试要在插件目录外运行（插件目录是 AstrBot 数据区）。

## 卸载

在 AstrBot WebUI 中禁用本插件，或删除插件目录。
