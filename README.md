# 回复去AI化质量层

一个让机器人回复更像真人的 AstrBot 插件。每次调用大模型前，它会注入一套「去 AI 腔」约束，并记住本会话最近回复里反复出现的开头，提醒模型换着说。

它做两件事：

1. **固定规则**：写给模型的通用约束，幂等写入 system prompt。只做减法，不碰人设的性格、称呼、情绪和口头禅。采用 natural-talk v2.1.0（MIT）「作为 System Prompt」原文 + 插件附加安全条款（来源标注见 `quality_rules.py` 与 CHANGELOG）。
2. **动态提醒**：记录最近回复开头与高置信度套话信号；下一轮以轻量提示要求换说法。

## 它会提醒模型避开这些

默认检测只抓**高置信度**信号，避免把正常技术写作误判成 AI 腔。

**末尾模板**（仅当回复以这些短语收尾时命中，出现在句中不报）：

- 客服收尾：`希望对你有帮助`、`希望这能帮到你`、`如果还有问题`、`随时问我`
- 空泛打气收尾：`一起加油`、`未来可期`、`砥砺前行`
- 收尾腔总结：`综上所述`、`由此可见`

完整列表见源码 `DEFAULT_ENDINGS`。固定规则原文可用 `/humanq rules` 查看（与词表无关）。

**AI 自我暴露**（任意位置精确命中一次即提醒）：

- `作为AI`、`根据我的训练`、`截至我的知识更新`

**谄媚/预告式开场**（仅回复首部命中，出现在句中不报）：

- `好问题`、`让我来`、`感谢你的提问`

**结构连发**（同一回复内出现至少 2 次）：

- 破折号 `——` 连发
- `然而` 连发

**路标词堆砌**（同一回复内合计出现至少 3 次）：

- `事实上` / `实际上` / `换句话说` / `本质上` / `归根结底` / `与此同时`

**重复开头**：默认统计最近 8 条回复的开头，同一开头出现 ≥3 次，下一轮提醒换说法。

**自定义避用词**（`custom_cliches`）：任意位置精确命中一次即加入本轮提醒；建议单条 ≤20 字。

> 正文里的「总的来说」「事实上」等连接词**单次**出现不会被默认拦截（路标词需 ≥3 次、收尾词需在结尾）；需要更严拦截时请写入 `custom_cliches`。

## 工作原理

- **固定规则**幂等写入 `system_prompt`（带标记，不重复注入，不进入聊天历史）；升级插件后旧版本规则块自动剥离（system_prompt 按段落、历史按 legacy 标记），避免新旧并存。
- **动态提醒**以本轮临时消息块注入。在 AstrBot 4.23+ 中，该块可能随 user 上下文入库；插件会在每轮**原位替换**为最新提示，或在状态清空时**移除**旧块，避免失效约束残留、也不会多块累积。
- 每次回复后更新会话状态；写盘在工作线程执行，不阻塞消息响应。
- 动态块依赖宿主 `TextPart`；环境不兼容时固定规则仍生效，动态提醒自动降级关闭。

## 快速开始

1. 在 AstrBot 管理面板 → 插件市场导入本仓库，或手动将 zip 解压到插件目录；
2. 支持 AstrBot `>=4.23,<5`，版本不满足时会有兼容提示；
3. 默认全部开启，装完即可生效，无需配置。

> 修改配置后需在管理面板**重载插件**生效。

## 命令

指令组 `humanq`，全部子命令仅**管理员**可用，作用范围均为**当前会话**（不同群/私聊互不影响）。

| 命令 | 作用 |
|------|------|
| `/humanq status` | 查看当前会话状态与累计注入次数 |
| `/humanq on` | 启用当前会话 |
| `/humanq off` | 关闭当前会话（直到再次 on） |
| `/humanq reset` | 清空当前会话的提醒记录 |
| `/humanq rules` | 查看固定规则原文 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enabled` | true | 总开关。关闭后插件仍加载，但不注入规则、不记录状态 |
| `inject_stable_rules` | true | 注入固定规则。与其它改写 system 的插件冲突时可关闭 |
| `inject_runtime_state` | true | 注入动态提醒 |
| `max_runtime_hint_chars` | 600 | 每轮动态提示的最大字符数（80–3000，超界自动夹取） |
| `recent_reply_window` | 8 | 重复开头检测范围：统计最近 N 条回复的开头，同一开头出现 ≥3 次即提醒换说法（3–50，小于 3 夹到 3） |
| `state_retention_days` | 14 | 会话状态超过该天数未更新自动清理（1–365） |
| `custom_cliches` | 空 | 自定义避用词，每行一个，命中即加入本轮提醒。建议单条 ≤20 字，超长不生效 |
| `disabled_sessions` | 空 | 禁用会话列表，每行一个群号（如 `123456`）或完整来源标识 |
| `debug_log` | false | 调试日志，开启后每次注入输出 debug 日志 |

旧配置项 `prompt_injection_mode` 已移除，留在配置文件里会被安全忽略。

## 数据与隐私

状态保存在插件数据目录的 `runtime_state.json`，只记录最近回复的开头与命中的避用词，**不保存完整聊天记录**。

## 测试（维护者）

测试已随仓库发布（`tests/`），在插件仓库根目录运行：

```
python -m unittest discover -s tests -v
python -m compileall -q main.py quality_rules.py runtime_state.py tests
ruff format --check .
ruff check .
```

装有兼容 AstrBot 时以真实宿主运行全部用例；无宿主或版本不兼容时，依赖宿主 API 的流程用例（`test_main_flow.py`）自动跳过，其余用例以无宿主方式运行。勿在 AstrBot 数据区的部署目录中运行测试（会污染数据区），请在源码副本根目录运行。

## 卸载

在 AstrBot WebUI 中禁用本插件，或删除插件目录。
