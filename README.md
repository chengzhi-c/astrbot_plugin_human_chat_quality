# 回复去AI化质量层

一个让机器人回复更像真人的 AstrBot 插件。每次调用大模型前，注入一套「去 AI 腔」约束，并记住本会话最近回复里反复出现的开头，提醒模型换着说。

它做两件事：

1. **固定规则**：幂等写入 system prompt 的通用约束。只做减法，不碰人设的性格、称呼、情绪和口头禅。正文对齐 natural-talk 分层体系（MIT）+ 插件附加铁律。正式写作与创作/扮演请求自动让位。原文用 `/humanq rules` 查看。
2. **动态提醒**：记下最近回复开头和高置信度套话，下一轮用一条短提示要求换说法。正式写作与创作/扮演请求不注入。

## 快速开始

在 AstrBot 管理面板 → 插件市场导入本仓库，或把 zip 解压到插件目录。默认全部开启，装完即可用。改配置后在管理面板**重载插件**。AstrBot 版本需 `>=4.23,<5`。

## 命令

指令组 `humanq`，全部子命令仅**管理员**可用，作用范围均为**当前会话**。

| 命令 | 作用 |
|------|------|
| `/humanq status` | 查看真实启用/关闭原因、动态提醒能力、下一轮避用项与累计注入次数 |
| `/humanq on` | 启用当前会话 |
| `/humanq off` | 关闭当前会话（直到再次 on） |
| `/humanq reset` | 清空当前会话的提醒记录（不删人设或历史里的旧规则字） |
| `/humanq rules` | 查看固定规则原文 |
| `/humanq stats` | 查看本次运行的注入、信号与清理统计 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enabled` | true | 总开关。关闭后插件仍加载，但不注入规则、不记录状态 |
| `inject_stable_rules` | true | 注入固定规则。与其它改写 system 的插件冲突时可关闭 |
| `inject_runtime_state` | true | 注入动态提醒；关闭后仍记录轻量状态 |
| `max_runtime_hint_chars` | 157 | 每轮动态提示的最大字符数（80–157），只装入完整短语 |
| `recent_reply_window` | 8 | 重复开头看最近 N 条（3–50） |
| `state_retention_days` | 14 | 会话状态超过该天数未更新则清理（1–365） |
| `custom_cliches` | 空 | 自定义避用词，每行一个 |
| `disabled_sessions` | 空 | 禁用会话列表，每行一个群号（如 `123456`）或完整来源标识 |
| `debug_log` | false | 调试日志，开启后每次注入输出 debug 日志 |

## 它拦截什么

只抓高置信度信号，避免把正常技术写作判成 AI 腔。完整词表见 `signal_detectors.py`。误报控制见 `tests/fixtures/detector_eval.json`：这是作者编写的冻结夹具（207 条，dev 106 / holdout 101），门禁要求夹具内 0 误报 / 0 漏报，且每个内置命中名至少出现一次；它不是野生语料评测。代码围栏（含 `~~~`）和 URL 不参与检测。

- **末尾模板**（只认收尾）：客服收尾（`希望能帮到你`、`随时问我`、`I hope this helps`）、空泛打气（`未来可期`、`一起加油`）、万能收尾（`关键在于找到平衡`、`要结合实际情况`、`因人而异`）、收尾腔总结（`综上所述`、`由此可见`）
- **AI 自我暴露**（任意位置）：`作为AI`、`作为一个语言模型`、`根据我的训练`、`截至我的知识更新` 等
- **谄媚/宏观/起手式/复述开场**（只认回复首部）：`好问题`、`让我来`、`关于你提到的`、`关于您提到的`、`你问到了核心`、`在当今快速发展的时代`、`说白了`、`先说结论`、`让我们先来`、`下面我将` 等
- **谄媚整句**（任意位置）：`我完全理解你的感受`、`你说得太对了`
- **模糊假归因**（任意位置）：`有研究表明`、`业内普遍认为`
- **结构信号**（达到阈值才报，300 字为基准按篇幅放宽）：破折号 >2 次（动态提示强约束改用常规标点）、感叹号 >3 次、`然而` 连发 ≥2 次、路标词堆砌 >2 次
- **铁律与结构性表演**（命中即报，引号内角色台词豁免）：`不是…而是`、`与其…不如`、`与其说…不如说`、`看似…实则`、`很久…久到`、`真正的问题是`、`一句话总结：`、`核心是：`、`总结如下：`、`建议如下：` 冒号提示语、`——那就是/那是/原来/其实` 揭示性破折号
- **模糊叠加**：`可能或许` 紧邻或 `通常来说…可能`（≥1 次）
- **空泛气氛总结**（任意位置）：`空气仿佛凝固`、`眼中闪过一丝`、`时间仿佛静止` 等
- **编号小标题连发**：同级连续编号标题 ≥3 才报，普通标题打断
- **重复开头**：默认看最近 8 条回复，同一开头出现 ≥3 次，下一轮提醒换说法；覆盖 `确实`、`当然`、`对的`、`没错`、`哈哈` 等日常高频口癖
- **自定义避用词**（`custom_cliches`）：任意位置命中一次即加入本轮提醒；单条超过 20 字不生效

句中偶尔出现的「总的来说」「事实上」不会单独拦截。要更严，写入 `custom_cliches`。

## 工作原理

- **固定规则**幂等写入 `system_prompt`（marker 防重复，编辑过的当前块不重复注入），不进聊天历史。
- **动态提醒**只作用于本轮。历史中的旧提示只清理，不复活；不会越积越多。
- 宿主接口不兼容时固定规则仍在，动态提醒自动降级；写盘失败内存先生效，重试或退出时再写。

## 数据与隐私

状态保存在插件数据目录的 `runtime_state.json`，只记录最近回复的开头与命中的避用词，**不保存完整聊天记录**。

## 维护者

源码仓库带测试和发布脚本；部署 zip 不含这些。在仓库根目录：

```
python -S scripts/run_tests.py core    # 无宿主测试
python scripts/run_tests.py all        # 全部（需 AstrBot）
python -S scripts/eval_detector.py --check
python -S scripts/check_upstream_sync.py --upstream <natural-talk 目录>
python scripts/build_release.py        # 发布门禁
```

失败、跳过、意外成功都算红灯。不要在 AstrBot 数据区的部署目录里跑测试。

## 卸载

在 AstrBot WebUI 中禁用本插件，或删除插件目录。
