# 回复去AI化质量层

一个让机器人回复更像真人的 AstrBot 插件。每次调用大模型前，它会注入一套「去 AI 腔」约束，并记住本会话最近回复里反复出现的开头，提醒模型换着说。

它做两件事：

1. **固定规则**：写给模型的通用约束，幂等写入 system prompt。只做减法，不碰人设的性格、称呼、情绪和口头禅。正文用 natural-talk lite（MIT）；插件附加要求保留事实、任务优先、不把约束写进回复。用户直接问身份、能力边界或知识截止时间时，如实短答。来源见 `THIRD_PARTY_NOTICES.md`，原文用 `/humanq rules` 查看。
2. **动态提醒**：记下最近回复开头和高置信度套话；下一轮用一条短提示要求换说法。

## 它会提醒模型避开这些

默认只抓高置信度信号，避免把正常技术写作判成 AI 腔。英文短语按句首或句末匹配，大小写不敏感。

**末尾模板**（只认收尾，句中不报）：

- 客服收尾：`希望对你有帮助`、`希望这能帮到你`、`如果还有问题`、`随时问我`、`I hope this helps`
- 空泛打气：`一起加油`、`未来可期`、`砥砺前行`
- 收尾腔总结：`综上所述`、`由此可见`

**AI 自我暴露**（任意位置命中一次即提醒）：

- `作为AI`、`根据我的训练`、`截至我的知识更新`

**谄媚/预告式开场**（只认回复首部，句中不报）：

- `好问题`、`让我来`、`感谢你的提问`、`Great question`

**结构信号**（同一回复达到阈值才报；300 字为基准，更长按篇幅放宽）：

- 破折号（`—` / `–`，超过 2 次）
- 感叹号（全/半角，超过 3 次）
- `然而` 连发（至少 2 次）

**路标词堆砌**（超过 2 次，同上折算；短回复需 ≥3 次）：

- `事实上` / `实际上` / `换句话说` / `本质上` / `归根结底` / `与此同时`

**重复开头**：默认看最近 8 条回复，同一开头出现 ≥3 次，下一轮提醒换说法。

**自定义避用词**（`custom_cliches`）：任意位置命中一次即加入本轮提醒；单条超过 20 字不生效。

句中偶尔出现的「总的来说」「事实上」不会单独拦截。要更严，写入 `custom_cliches`。

## 工作原理

- **固定规则**写入 `system_prompt`，带标记，不重复，不进聊天历史。升级后可识别的旧规则会剥掉；无法核验的旧块会留下，以免误删人设。
- **动态提醒**只作用于本轮。已经进历史的旧提示会换成最新一条，本轮临时块先清再写，不会越积越多。关闭或清空时，先清掉可识别旧块。
- 关掉总开关、固定规则、动态提醒、当前会话或静态禁用时，同样先清理，再停止注入。
- 每次回复后更新会话状态。关掉动态提醒也会继续记开头，重新打开后接得上。写盘在后台，不挡回复；失败时内存先生效，命令会说明未落盘，重试或退出时再写。
- 动态块依赖宿主接口。环境不兼容时固定规则仍在，动态提醒自动关。

## 快速开始

在 AstrBot 管理面板 → 插件市场导入本仓库，或把 zip 解压到插件目录。默认全部开启，装完即可用。改配置后在管理面板**重载插件**。AstrBot 版本不满足 `>=4.23,<5` 时会有兼容提示。

## 命令

指令组 `humanq`，全部子命令仅**管理员**可用，作用范围均为**当前会话**（不同群/私聊互不影响）。

| 命令 | 作用 |
|------|------|
| `/humanq status` | 查看当前会话是否启用、下一轮避用项、累计注入次数 |
| `/humanq on` | 启用当前会话 |
| `/humanq off` | 关闭当前会话（直到再次 on） |
| `/humanq reset` | 清空当前会话的提醒记录 |
| `/humanq rules` | 查看固定规则原文 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enabled` | true | 总开关。关闭后插件仍加载，但不注入规则、不记录状态 |
| `inject_stable_rules` | true | 注入固定规则。与其它改写 system 的插件冲突时可关闭 |
| `inject_runtime_state` | true | 注入动态提醒；关闭后仍记录轻量状态 |
| `max_runtime_hint_chars` | 157 | 每轮动态提示的最大字符数（80–157），只装入完整短语 |
| `recent_reply_window` | 8 | 重复开头看最近 N 条（3–50） |
| `state_retention_days` | 14 | 会话状态超过该天数未更新则清理（1–365） |
| `custom_cliches` | 空 | 自定义避用词，每行一个 |
| `disabled_sessions` | 空 | 禁用会话列表，每行一个群号（如 `123456`）或完整来源标识 |
| `debug_log` | false | 调试日志，开启后每次注入输出 debug 日志 |

旧配置项 `prompt_injection_mode` 已移除，留在配置文件里会被安全忽略。

## 数据与隐私

状态保存在插件数据目录的 `runtime_state.json`，只记录最近回复的开头与命中的避用词，**不保存完整聊天记录**。

## 测试（维护者）

源码仓库带测试和发布脚本；部署 zip 不含这些。在仓库根目录：

```
python -S scripts/run_tests.py core
python scripts/run_tests.py host
python scripts/run_tests.py all
python scripts/build_release.py
```

`core` 用 `python -S`，不读已装的 AstrBot。`host` / `all` 需要受支持的 AstrBot。失败、跳过、意外成功都算红灯。不要在 AstrBot 数据区的部署目录里跑测试，以免写出 `data/`。

## 卸载

在 AstrBot WebUI 中禁用本插件，或删除插件目录。
