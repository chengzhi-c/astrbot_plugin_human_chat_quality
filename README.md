# 回复去AI化质量层

AstrBot 去 AI 腔插件。在模型调用前注入通用对话约束，并跟踪近期高频重复的回复开头与套话，在后续轮次提示模型更换表达。

主要功能：

1. **固定规则**：写入 system prompt 的基础约束，保持现有角色设定，对齐 natural-talk 规则集。正式写作与小说创作请求自动让位。可用 `/humanq rules` 查看。
2. **动态提醒**：记录近期回复开头与命中的套话，在下一轮作为简短提示传入，要求更换表达。

## 快速开始

在 AstrBot 管理面板 → 插件市场导入本仓库，或解压 release 包到插件目录。默认全部开启。修改配置后需在管理面板**重载插件**。依赖 AstrBot `>=4.23,<5`。

## 命令

指令组 `humanq`，所有子命令限**管理员**在**当前会话**使用。

| 命令 | 作用 |
|------|------|
| `/humanq status` | 查看当前启用状态、动态提醒状态与累计注入次数 |
| `/humanq on` | 启用当前会话 |
| `/humanq off` | 禁用当前会话 |
| `/humanq reset` | 清空当前会话的提醒记录 |
| `/humanq rules` | 查看当前固定规则原文 |
| `/humanq stats` | 查看本次进程运行的统计数据 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enabled` | true | 总开关。关闭后插件仍加载，但不注入规则、不记录状态 |
| `inject_stable_rules` | true | 注入固定规则。与其它改写 system 的插件冲突时可关闭 |
| `inject_runtime_state` | true | 注入动态提醒；关闭后仍记录轻量状态 |
| `max_runtime_hint_chars` | 157 | 每轮动态提示的最大字符数（80–157），只装入完整短语 |
| `recent_reply_window` | 8 | 重复开头看最近 N 条（3–50） |
| `state_retention_days` | 14 | 会话状态超过该天数未更新则清理（1–365） |
| `custom_cliches` | 空 | 自定义避用词，每行一个 |
| `disabled_sessions` | 空 | 禁用会话列表，每行一个群号（如 `123456`）或完整来源标识 |
| `debug_log` | false | 调试日志，开启后每次注入输出 debug 日志 |

## 检测项目

检测器拦截高置信度特征，放行正常技术写作。代码块（含 `~~~`）与 URL 不参与检测。冻结评测集见 `tests/fixtures/detector_eval.json`（207 例，覆盖 dev 106 / holdout 101，门禁要求 0 误报 / 0 漏报）。

- **末尾模板**（仅结尾匹配）：客服收尾（`希望能帮到你`、`随时问我`、`I hope this helps`）、空泛打气（`未来可期`、`一起加油`）、万能收尾（`关键在于找到平衡`、`要结合实际情况`、`因人而异`）、总结套话（`综上所述`、`由此可见`）
- **AI 身份暴露**（全句匹配）：`作为AI`、`作为一个语言模型`、`根据我的训练`、`截至我的知识更新` 等
- **问候与起手式**（仅开头匹配）：`好问题`、`让我来`、`关于你提到的`、`关于您提到的`、`你问到了核心`、`在当今快速发展的时代`、`说白了`、`先说结论` 等
- **谄媚整句**（全句匹配）：`我完全理解你的感受`、`你说得太对了`
- **模糊归因**（全句匹配）：`有研究表明`、`业内普遍认为`
- **高频标点与路标词**（按篇幅折算阈值，基准 300 字）：破折号 >2 次、感叹号 >3 次、`然而` 连发 ≥2 次、路标词堆砌 >2 次
- **特定句式**（引号内对白豁免）：`不是…而是`、`与其…不如`、`与其说…不如说`、`看似…实则`、`很久…久到`、`真正的问题是`、冒号引列表（`总结如下：`、`建议如下：`）、揭示性破折号（`——那就是`、`——原来`）
- **推测词叠加**：`可能或许`、`通常来说…可能` 等连用
- **空泛气氛描写**：`空气仿佛凝固`、`眼中闪过一丝`、`时间仿佛静止` 等
- **连续编号标题**：同级连续编号标题 ≥3 个
- **重复开头**：统计最近 8 条回复，同一开头出现 ≥3 次触发提醒，涵盖 `确实`、`当然`、`对的`、`没错`、`哈哈` 等常见口头语
- **自定义避用词**（`custom_cliches`）：命中配置词即加入下一轮提示；单个词超过 20 字忽略

在 `custom_cliches` 中添加条目可扩展检测项。

## 工作原理

- **固定规则**：写入 `system_prompt`，使用 marker 标识防重，不写入聊天历史。
- **动态提醒**：随单轮请求发送，并在每轮请求前清理历史上下文中的注入块。
- **容错处理**：接口受限时动态提醒自动降级，固定规则保持生效；写盘失败时先保存在内存，重试或关闭时落盘。

## 数据存储

状态文件位于插件数据目录的 `runtime_state.json`，记录最近回复开头与命中的避用词，不保存聊天全文。

## 维护与测试

仓库包含完整测试与打包门禁：

```bash
python -S scripts/run_tests.py core    # 核心单元测试（无宿主环境）
python scripts/run_tests.py all        # 全量测试（需 AstrBot 环境）
python -S scripts/eval_detector.py --check
python -S scripts/check_upstream_sync.py --upstream <natural-talk 目录>
python scripts/build_release.py        # 门禁核验与打包
```

## 卸载

在 AstrBot WebUI 中停用或直接删除插件目录。
